# 🛕 Smart Dharsan System

An AI-powered web application that predicts temple crowd levels and helps devotees choose the best time for darshan. The system analyzes historical and real-time data to estimate crowd density and waiting time, enabling better temple management and a smoother experience for devotees.

---

## 📌 Project Overview

The Smart Dharsan System is designed to reduce overcrowding and long waiting queues in temples by providing intelligent crowd prediction. Instead of relying on manual estimates, the system uses machine learning techniques to forecast visitor traffic and display expected crowd levels.

This project also includes an administrator dashboard for managing temple data and monitoring predictions, allowing temple authorities to make informed decisions.

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/Smart-Dharsan-System.git
```

### Move to Project Folder

```bash
cd Smart-Dharsan-System
```

### Configure Database

- Create a MySQL database.
- Import the SQL file from the `database` folder.
- Update database credentials in the PHP configuration file.

### Start Local Server

Use **XAMPP** or **WAMP**.

- Start Apache
- Start MySQL
- Open your browser

```
http://localhost/Smart-Dharsan-System/
```
